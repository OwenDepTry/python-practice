# Python Problem Solving

Bộ sưu tập lời giải các bài tập lập trình bằng Python, phục vụ việc luyện tập tư duy thuật toán, kỹ năng giải quyết vấn đề và cách triển khai mã nguồn.

## Nội dung

Các bài tập được bổ sung theo quá trình luyện tập, bao gồm:

- **Số học:** số nguyên tố, tính chia hết, giai thừa và xử lý chữ số.
- **Chuỗi:** duyệt, biến đổi và xử lý chuỗi.
- **Cấu trúc dữ liệu:** list, tuple, set và dictionary.
- **Thuật toán:** tìm kiếm, sắp xếp và đệ quy.

## Chạy chương trình

**Yêu cầu:** Python 3.

Mở terminal tại thư mục chứa mã nguồn và chạy:

```bash
python <ten_file>.py
```

Trên Windows, có thể sử dụng:

```bash
py <ten_file>.py
```

Nhập dữ liệu theo yêu cầu của từng bài. Kết quả được hiển thị trực tiếp trên terminal.
